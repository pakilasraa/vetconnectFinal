## 1. Introduction

VetConnect V2 is a web-based veterinary clinic system that allows pet owners to:
- Manage their pet profiles
- Book and manage appointments
- View pet medical and vaccination information
- Maintain their own account profile

This manual explains how clients can use the system step by step.

## 2. System Requirements

- Device: Desktop/laptop or mobile device with browser
- Browser: Google Chrome, Microsoft Edge, Mozilla Firefox (latest versions)
- Internet: Required if hosted online; local network if deployed locally
- User Account: Registered `pet_owner` account

## 3. Accessing the System

1. Open the VetConnect V2 login page.
2. Enter your email and password.
3. Click **Log in**.
4. If credentials are correct, you are redirected to the **Client Dashboard**.

If you do not have an account:
1. Click **Register**.
2. Fill in required details.
3. Submit registration.
4. Log in using your registered account.

## 4. Client Dashboard

After login, the dashboard displays:
- Quick statistics (pets, appointments, records)
- Upcoming appointments
- Recent medical record entries
- Shortcuts to commonly used pages

Recommended action:
- Check upcoming schedules first.
- Verify pet information before booking new appointments.

## 5. Managing Pets (My Pets)

### 5.1 View pets
1. Go to **My Pets**.
2. Review the pet list and summary information.

### 5.2 Add a pet
1. Click **Add Pet**.
2. Enter required details (example: name, species, breed, birthdate, sex).
3. Upload a pet photo if available.
4. Click **Save**.

### 5.3 Edit a pet
1. Open a pet entry.
2. Click **Edit**.
3. Update the needed fields.
4. Click **Update/Save**.

### 5.4 View pet records
Within pet pages or summaries, users can view:
- Medical history summary
- Vaccination history summary

## 6. Managing Appointments

### 6.1 Book an appointment
1. Go to **Appointments**.
2. Click **Book Appointment**.
3. Select pet, date, time slot, and service type.
4. Enter notes if needed.
5. Submit the form.

Important:
- Appointment slots cannot be double-booked.
- If a slot is already taken, select another schedule.

### 6.2 View appointments
In the Appointments page, users can:
- See list view of their appointments
- Check status (pending, confirmed, completed, cancelled)
- Use calendar-based availability view (if shown)

### 6.3 Edit appointment
1. Open the appointment entry.
2. Click **Edit**.
3. Change allowed fields (date/time/details).
4. Save changes.

### 6.4 Cancel appointment
1. Open appointment details.
2. Click **Cancel**.
3. Confirm cancellation.

Note:
- Past pending/confirmed appointments may be auto-cancelled by system rules.

## 7. Vaccination Records (Client View)

1. Open **Vaccination Records** from the client menu.
2. Review vaccine entries associated with your pets.
3. Check status and schedule details.

Client users can view vaccination records, while management actions are handled by admin users.

## 8. Profile Management

1. Go to **Profile**.
2. Update personal information (name, email, photo if enabled).
3. Save updates.

For password updates:
1. Use the password update option in profile/account settings.
2. Enter current password and new password.
3. Confirm and save.

## 9. Common Errors and Solutions

- Incorrect email/password
  - Recheck credentials and keyboard caps lock.
  - Use password reset if needed.

- Access denied / not authorized
  - Ensure you are logged in with a valid pet owner account.
  - Contact admin if account role is incorrect.

- Slot unavailable during booking
  - Choose another time/date because slot is already reserved.

- Profile photo not loading
  - Refresh page and verify upload format/size.
  - Report to admin if issue persists.

## 10. User Best Practices

- Keep your profile details up to date.
- Double-check pet data before booking appointments.
- Monitor appointment status regularly.
- Cancel appointments early if unavailable.
- Keep account password secure.
